## Description (max 4000)
Mesh+ 讓你在沒有網路、沒有手機訊號的地方，也能透過 LoRa Mesh 無線電和附近的人傳訊息。用藍牙配對一台 Meshtastic® 無線電後，你的訊息會在 Mesh 網路中從一台無線電跳到另一台，無論是登山健行、在音樂祭現場，還是網路中斷的時候，都能保持聯絡。

設定只要大約一分鐘：選擇你的無線電，輸入它螢幕上顯示的 PIN 碼，再選好地區、取個名字，就能開始聊天。

公開聊天室、私人聊天室和私訊都整理在同一個列表裡，未讀訊息會用標記提醒你。你可以用 QR Code 或連結分享聊天室，掃描聊天室的 QR Code 就能加入，不想收到通知的對話也可以設為靜音。私訊由無線電進行端對端加密。

Mesh+ 會在背景保持連線，有新訊息時會通知你。

每一項無線電設定都附有簡短的說明，告訴你它的用途以及什麼時候需要調整，從無線電預設組合、最大跳數，到藍牙配對、省電和螢幕，都能放心設定。

你可以把所有無線電集中在一處管理，並從頂端列隨時切換。

如果你還沒有無線電，可以先試試內建的示範模式。

Mesh+ 沒有帳號、廣告，也不做使用分析，你的訊息只會保存在你的 iPhone 上。Mesh+ 是獨立的開放原始碼 App，與 Meshtastic LLC 沒有任何關聯，也未經其認可。Meshtastic® 是 Meshtastic LLC 的註冊商標。
