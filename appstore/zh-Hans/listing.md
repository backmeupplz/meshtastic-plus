## Description (max 4000)
Mesh+ 让你在没有网络、没有手机信号的地方，也能通过 LoRa Mesh 电台和附近的人发消息。用蓝牙配对一台 Meshtastic® 电台后，你的消息会在 Mesh 网络中从一台电台跳到另一台，无论是在徒步途中、音乐节现场，还是网络中断的时候，都能保持联系。

设置只需大约一分钟：选择你的电台，输入它屏幕上显示的 PIN 码，再选好地区、起个名字，就可以开始聊天了。

公开房间、私密房间和私信都在同一个列表里，未读消息会用标记提醒你。你可以用二维码或链接分享房间，扫描房间的二维码就能加入，不想收到通知的对话可以设为静音。私信由电台进行端到端加密。

Mesh+ 会在后台保持连接，有新消息时会通知你。

每一项电台设置都附有简短的说明，告诉你它的作用以及什么时候需要修改，从无线电预设、最大跳数，到蓝牙配对、省电和屏幕，都能放心调整。

你可以把所有电台集中在一处管理，并在顶栏中随时切换。

如果你还没有电台，可以先试试内置的演示模式。

Mesh+ 没有账号、广告或数据分析，你的消息只保存在你的 iPhone 上。Mesh+ 是一款独立的开源应用，与 Meshtastic LLC 没有任何关联，也未获得其认可。Meshtastic® 是 Meshtastic LLC 的注册商标。
