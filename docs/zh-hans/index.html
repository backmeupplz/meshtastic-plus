获取 App

在没有信号的地方，也能给朋友发消息。

Mesh+ 是一款好上手的 Android App，专为 Meshtastic 电台而做。把一台口袋大小的 LoRa 电台连上手机，你的消息就会在电台之间一跳一跳地翻过山岭、越过山谷，一路上不需要基站、Wi-Fi 或互联网。

Mesh+ 免费开源，大约只有 3 MB，需要 Android 12 或更高版本。还没有电台？内置的演示模式可以让你先看看它是什么样子。

发布视频

三十秒看懂 Mesh+ 能做什么。

打开声音，快速看一遍私密房间、在 Mesh 网络中一跳跳传递的消息、固件更新和 SMS 中继。

工作原理

从拆开包装到发出第一条消息，大约只需要一分钟。

Meshtastic 电台通过远距离 LoRa 无线电互相转发消息，所以通信范围内的每一台电台都成了网络的一部分。你的手机就靠 Mesh+ 与自己的电台沟通。

准备一台 Meshtastic 电台。

Mesh+ 适用于运行 Meshtastic 固件 2.x 的电台，例如 Heltec Mesh Node T114 或 RAK4631。你想联系的朋友也需要一台，而中间的每一台电台都会帮忙把消息传得更远。

把它连上手机。

可以输入电台屏幕上显示的 PIN，通过 Bluetooth 配对，也可以用 USB-C 线插上，由手机给电台供电。Mesh+ 会记住你的电台，下次重新连接只需轻点一下。

选择地区，起个名字。

新电台在知道该用哪个频段之前不会发射，所以 Mesh+ 会问你一次，并根据手机所在的国家或地区推荐合适的地区。选好你在 Mesh 网络里显示的名字，就可以开始聊天了。

聊天

公开聊天、私密房间和私信，都在同一个列表里。

公开频道是附近所有人共用的开放房间。私密房间经过加密，只有你邀请的人才能阅读；私信则由电台固件进行端到端加密。

  • 消息下方的对勾会告诉你，它已被另一台电台转发，或者已被你朋友的电台收到。
  • 未读标记会显示有什么新消息，你也可以把不想被打扰的房间或联系人设为静音。
  • 连接期间，Mesh+ 会在后台持续运行，有消息到达时通知你。
SMS 中继

只要有一部手机有信号，整个小队都能收发短信。

在野外，常常只有一个人（也许在大本营，也许在山脊上）能有一格手机信号。把这部手机变成中继，Mesh 网络里的每个人就都能通过它收发普通短信。

  1. 基站只覆盖到一部手机。
  2. 大本营的手机有信号，并运行中继。
  3. 电台在 Mesh 网络中把短信一路传下去。
  4. 你的手机没有信号，只连着一台电台。

短信和来电会出现在一个私密房间里。

中继手机收到的每一条 SMS，以及它的来电和未接来电，都会发布到你选定的私密房间，Mesh+ 会把它们显示成大家熟悉的短信对话。

房间里的任何人都可以回短信。

滑动一条短信即可回复，也可以轻点 SMS 按钮，给任意号码或联系人写短信。中继手机会用它自己的号码发出，发出后会出现一个对勾。

使用其他 Meshtastic App 的朋友也能参与。

中继消息是纯文本，所以使用其他 Meshtastic App 的人也能阅读，并且只需输入 /sms +15551234567 your message 就能发送短信。

中继房间里的每个人都能看到这部手机收到的短信，也能用它的号码发送 SMS，所以请只让你信任的人加入房间。短信按你的运营商的常规资费收费。

开启只需要几秒钟。

在有信号的那部手机上，打开“设置”，进入“SMS 中继”，选一个私密房间（或让 Mesh+ 创建一个名为 Relay 的房间），然后打开开关。Android 会询问一次短信和电话权限，中继运行期间，通知会一直保留。

中继在你开启之前是关闭的，你也可以随时在同一个页面把它关掉。

邀请

用二维码或链接邀请朋友加入私密房间。

轻点几下就能创建房间，可以分享成供扫描的二维码，也可以在出发前把链接发给朋友。Mesh+ 使用标准的 Meshtastic 邀请格式，所以官方 Meshtastic App 的链接能在 Mesh+ 中打开，你的链接也能在官方 App 中打开。

  • 每个私密房间都有自己的加密密钥，所以没有收到邀请的人，即使他们的电台帮忙转发了消息，也无法阅读其中的内容。
  • 扫一下二维码或粘贴链接就能加入，退出只需轻点一下。
节点

看到你的节点能收到的每一台电台。

“节点”标签页会列出你的电台收到过的所有人，收藏的排在最前面，最近两小时内收到过的会带有在线标记。轻点一个节点，可以看到它上次被收到的时间、相隔几跳、信号强弱和剩余电量，还可以给它发消息，或把它加入收藏；收藏保存在你的电台上。

无线电设置

每项设置都用大白话说明它的作用。

角色、转发、无线电预设、最大跳数、发射功率、位置分享、省电、屏幕和 Bluetooth 配对，都只需轻点一下就能找到，每一项还附有简短的说明，告诉你它的作用以及什么时候需要改。Mesh+ 会把你的修改一起保存，所以电台只会重启一次。

  • 页面顶部会显示你的电台是哪种板子、运行的固件版本和电量。
  • 出问题时，你可以清除节点列表，在保留身份的同时重置设置，或者彻底恢复出厂设置。
固件

不用电脑，也能更新电台固件。

Meshtastic 发布新的稳定版后，Mesh+ 会直接在电台的设置里提供更新。Heltec T114 和 RAK4631 这类 nRF52 板子，通过 USB 线更新大约只要一分钟；不想插线时，也可以通过 Bluetooth 更新，大约需要十分钟。

  • 你可以选择任何已发布的版本，包括预发布版本，也可以退回到旧版本。
  • 你的设置、房间和消息都会保留，卡在更新模式的电台也可以在连接页面救回来。
  • ESP32 板子需要在电脑上通过 flasher.meshtastic.org 更新。
更多功能

那些小细节，我们也都照顾到了。

你所有的电台，轻点一下就能切换。

在顶部栏里就能在不同电台之间切换，并看到每一台是哪种板子、运行什么固件、还剩多少电。

没有电台也能试用。

内置的演示模式会模拟一台带有房间、私信、回复和设置的电台，让你在买硬件之前先看一看。

吵闹的房间可以静音。

任何房间或私信都可以设为静音，聊天列表里带斜线的铃铛会提醒你哪些处于静音状态。

你的消息只属于你。

没有账号，没有广告，也没有数据分析，你的消息记录只保存在你的手机上。

代码是开源的。

Mesh+ 在 GitHub 上公开开发，任何人都可以阅读代码、自行编译并提交改进。

一根线就能给电台供电。

通过 USB-C，手机也会给电台供电，所以即使电台没有电池，它也能继续工作。

你需要准备什么

Mesh+ 上手只需要很少的东西。

任何运行 Android 12 或更高版本的手机都可以。Mesh+ 大约占用 3 MB，也不需要账号。
你的电台需要运行 Meshtastic 固件 2.x。这样的电台都可以通过 Bluetooth 连接；通过 USB 连接时，Mesh+ 已在 Heltec T114 这类 nRF52 板子上测试过。
你的朋友也需要电台。他们可以使用 Mesh+ 或任何其他 Meshtastic App，通信范围内的每一台电台都会让 Mesh 网络更大。
常见问题

这里是大家问得最多的问题的答案。

需要手机信号或互联网吗？

不需要。消息通过 LoRa 在 Meshtastic 电台之间传递，所以只要你们的电台能互相联系上，就能聊天。Mesh+ 只在检查和下载固件更新时才会联网。

消息能传多远？

两台手持电台只要视线开阔，往往可以隔着几公里互相联系，中间的每一台电台还能把消息继续往下传。山丘、建筑和树木会缩短距离，所以大家喜欢把中继站架在高处。

我能和使用官方 Meshtastic App 的人聊天吗？

可以。Mesh+ 使用同一套协议，所以不管大家用哪个 App，同一频道里的人都能看到彼此的消息，房间邀请链接也可以双向使用。

谁能看到通过 SMS 中继的短信？

中继房间里的每个人都能看到中继手机收到的短信和来电，也能用它的号码发送短信。房间是加密的，所以房间之外的人看不到，但请谨慎选择成员。任何内容都不会发送给我们或任何服务器。

Mesh+ 在 Google Play 或 F-Droid 上有吗？

Mesh+ 已上架 Google Play，也正在上架 F-Droid 的路上。你还可以在本页安装 APK：在手机上打开文件，当 Android 询问时，允许你的浏览器安装应用。

有 iPhone 版本吗？

目前 Mesh+ 只有 Android 版。使用 iPhone 的朋友可以用官方 Meshtastic App 加入你的房间。

Mesh+ 要花钱吗？

不要。Mesh+ 免费开源，没有账号、广告、数据分析，也没有应用内购买。
