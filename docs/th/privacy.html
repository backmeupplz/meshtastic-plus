นโยบายความเป็นส่วนตัว

อัปเดตล่าสุดเมื่อวันที่ 27 ตุลาคม 2026

หน้านี้เป็นฉบับแปล หากแตกต่างจากต้นฉบับภาษาอังกฤษ ให้ถือต้นฉบับภาษาอังกฤษเป็นข้อความที่มีผลผูกพัน

Mesh+ เป็นแอปสำหรับ Android และ iPhone ที่ใช้งานร่วมกับวิทยุ Meshtastic แอปไม่มีบัญชี ไม่มีเซิร์ฟเวอร์ของตัวเอง ไม่มีโฆษณา และไม่มีการวิเคราะห์การใช้งาน และไม่เก็บรวบรวม ขาย หรือแบ่งปันข้อมูลส่วนบุคคลของคุณกับเราหรือผู้อื่น หน้านี้อธิบายว่าแอปจัดการข้อมูลอะไรบ้างและข้อมูลนั้นไปที่ไหน

ข้อความและวิทยุของคุณ

ข้อความที่คุณส่งและรับเดินทางระหว่างโทรศัพท์ของคุณกับวิทยุ Meshtastic ของคุณเองผ่าน Bluetooth หรือสาย USB และจากนั้นผ่านเมชวิทยุไปยังวิทยุของผู้อื่น ข้อความในห้องถูกเข้ารหัสด้วยคีย์ของห้อง และข้อความส่วนตัวถูกเข้ารหัสแบบต้นทางถึงปลายทางโดยเฟิร์มแวร์ Meshtastic ประวัติข้อความ รายการวิทยุที่คุณเคยใช้ และการตั้งค่าของคุณถูกเก็บไว้ในโทรศัพท์ของคุณเท่านั้น ภายในพื้นที่จัดเก็บส่วนตัวของแอป และจะถูกลบเมื่อคุณถอนการติดตั้งแอป

Bluetooth, USB และกล้อง

แอปใช้ Bluetooth เพื่อค้นหาและเชื่อมต่อกับวิทยุ Meshtastic เท่านั้น และใช้ USB (บน Android) เพื่อสื่อสารกับวิทยุที่เสียบอยู่กับโทรศัพท์ของคุณเท่านั้น แอปใช้กล้องเฉพาะขณะที่คุณสแกน QR โค้ดของห้อง และภาพจะไม่ออกจากโทรศัพท์ของคุณ แอปไม่ใช้ตำแหน่งของคุณ

อินเทอร์เน็ต

แอปเชื่อมต่ออินเทอร์เน็ตเฉพาะเมื่อคุณเปิดหน้าจอเฟิร์มแวร์หรืออัปเดตวิทยุ โดยจะถาม api.meshtastic.org ว่ามีเฟิร์มแวร์เวอร์ชันใดบ้าง และดาวน์โหลดแพ็กเกจเฟิร์มแวร์จาก GitHub (raw.githubusercontent.com) คำขอเหล่านี้ไม่มีข้อมูลส่วนบุคคลใดๆ แต่เช่นเดียวกับคำขอเว็บทั่วไป เซิร์ฟเวอร์เหล่านั้นจะเห็นที่อยู่ IP ของคุณ

การส่งต่อ SMS และสายโทรเข้า (ไม่บังคับ เฉพาะ Android)

การส่งต่อจะปิดอยู่จนกว่าคุณจะเปิด เมื่อคุณเปิด Android จะขอสิทธิ์ในการรับและส่ง SMS และอ่านสถานะโทรศัพท์และประวัติการโทร ขณะที่เปิดอยู่ แอปจะส่งต่อข้อความ หมายเลขผู้ส่ง และเวลาของ SMS ที่โทรศัพท์ของคุณได้รับ รวมถึงหมายเลขของสายโทรเข้า ไปยังห้อง Meshtastic ส่วนตัวที่คุณเลือก และส่ง SMS ที่สมาชิกในห้องนั้นร้องขอ ข้อมูลนี้ส่งผ่านเมชวิทยุไปยังคนในห้องนั้นเท่านั้น และไม่เคยถูกส่งมาถึงเราหรือเซิร์ฟเวอร์ใดเลย จะมีการแจ้งเตือนแสดงขณะที่การส่งต่อเปิดอยู่ และคุณปิดได้ทุกเมื่อในแอป ใครก็ตามที่มีคำเชิญของห้องนั้นอ่านข้อความที่ส่งต่อและส่ง SMS จากหมายเลขของคุณได้ ดังนั้นควรแชร์คำเชิญกับคนที่คุณไว้ใจเท่านั้น

การแจ้งเตือน

แอปแสดงการแจ้งเตือนเมื่อมีข้อความใหม่ และขณะที่แอปยังเชื่อมต่อกับวิทยุของคุณอยู่เบื้องหลัง

การบล็อกและการรายงาน

การบล็อกวิทยุจะซ่อนข้อความจากวิทยุนั้นบนโทรศัพท์ของคุณ รายการวิทยุที่บล็อกจะอยู่บนโทรศัพท์ของคุณ หากคุณรายงานข้อความ แอปอีเมลของคุณจะเปิดอีเมลถึงเราพร้อมข้อความที่ถูกรายงาน ID วิทยุของผู้ส่ง และเวลา จะไม่มีอะไรถูกส่งเว้นแต่คุณจะส่งอีเมลนั้นเอง และเราใช้ข้อมูลนั้นเพื่อจัดการกับรายงานเท่านั้น

เว็บไซต์นี้

meshplus.app นับจำนวนผู้เข้าชมด้วย Lumen ตัวนับหน้าเว็บขนาดเล็กที่นักพัฒนาดูแลเอง ไม่ใช้คุกกี้ ไม่เก็บที่อยู่ IP และไม่เก็บสิ่งใดที่ระบุตัวคุณได้ ผู้เข้าชมถูกนับด้วยรหัสที่เปลี่ยนทุกวัน และแยกจากแอป

เด็ก

Mesh+ ไม่ได้มุ่งเป้าไปที่เด็กอายุต่ำกว่า 13 ปี และไม่เก็บข้อมูลของเด็กโดยรู้เห็น

การเปลี่ยนแปลงและการติดต่อ

หากนโยบายนี้เปลี่ยนแปลง เวอร์ชันใหม่จะถูกโพสต์ในหน้านี้พร้อมวันที่ใหม่ มีคำถามไหม เปิด issue ได้ที่ github.com/backmeupplz/meshtastic-plus
