วิธีอัปเดตเฟิร์มแวร์ Meshtastic จากโทรศัพท์

ตรวจเทียบกับซอร์สของ Mesh+ และรายการรุ่นของ Meshtastic เมื่อ 3 พฤศจิกายน 2026

คุณอัปเดตวิทยุ Meshtastic ที่ใช้ชิป nRF52840 เครื่องไหนก็ได้ (เช่น Heltec Mesh Node T114, RAK WisBlock 4631 หรือ LILYGO T-Echo) จากโทรศัพท์ Android โดยตรงด้วย Mesh+ เพียงเปิด การตั้งค่าโหนด เลือกเวอร์ชัน แตะ ติดตั้ง แล้วรอประมาณหนึ่งนาทีครึ่งผ่านสาย USB-C การตั้งค่า ห้อง และข้อความของคุณจะอยู่ครบเหมือนเดิม ส่วนบอร์ด ESP32 อย่าง Heltec V3 ยังคงต้องใช้คอมพิวเตอร์และ flasher.meshtastic.org

สิ่งที่ต้องมี

  • Mesh+ สำหรับ Android (Google Play หรือ APK) บน Android 12 ขึ้นไป พร้อมการเชื่อมต่ออินเทอร์เน็ตสำหรับดึงไฟล์เฟิร์มแวร์
  • วิทยุที่ใช้ Meshtastic 2.x บนบอร์ด nRF52 หนึ่งใน 39 รุ่นที่อยู่ในตารางฮาร์ดแวร์ของ Mesh+ (รวมทั้งหมด 118 บอร์ด)
  • สาย USB-C สำหรับรับส่งข้อมูล หรือโหนดที่จับคู่ผ่าน Bluetooth ไว้แล้ว

อัปเดตเฟิร์มแวร์ Meshtastic ทีละขั้นตอน

  1. เปิด การตั้งค่าโหนด เชื่อมต่อวิทยุใน Mesh+ แล้วไปที่ การตั้งค่าโหนด การ์ดบอร์ดด้านบนจะแสดงบอร์ดที่ตรวจพบ ชิป และเฟิร์มแวร์ที่รันอยู่ เช่น nRF52840 · เฟิร์มแวร์ 2.7.15
  2. แตะ อัปเดต หรือเปิด ตัวเลือกเฟิร์มแวร์ หาก Meshtastic มีบิลด์เสถียรที่ใหม่กว่าสำหรับบอร์ดของคุณ การ์ดจะแสดง อัปเดตเป็น ตามด้วยเลขเวอร์ชัน แต่ถ้าไม่มี จะแสดง เป็นเวอร์ชันล่าสุด · ตัวเลือกเฟิร์มแวร์ ซึ่งพาไปหน้าเลือกเวอร์ชันเดียวกัน
  3. เลือกเวอร์ชัน หน้าจอ เฟิร์มแวร์ จะแสดงทุกเวอร์ชันที่ Meshtastic เผยแพร่ให้บอร์ดของคุณ โดยเรียงจากใหม่สุด พร้อมป้าย ล่าสุด และ ติดตั้งแล้ว หากต้องการบิลด์อัลฟา ให้เปิด รวมเวอร์ชันทดสอบ ส่วนการเลือกเวอร์ชันที่เก่ากว่าจะมีคำเตือนขึ้นก่อน
  4. แตะ ติดตั้ง Mesh+ จะดึงไฟล์ zip จากเว็บไซต์เฟิร์มแวร์ของ Meshtastic รีสตาร์ทโหนดเข้าสู่โหมดอัปเดต ขอสิทธิ์ USB ลบเฟิร์มแวร์เก่า แล้วแฟลชบิลด์ใหม่พร้อมแถบความคืบหน้า
  5. รอการรีสตาร์ท เมื่อแถบเต็ม โหนดจะรีสตาร์ทเข้าสู่เวอร์ชันใหม่และ Mesh+ จะเชื่อมต่อกลับเองโดยอัตโนมัติ การตั้งค่า ห้อง และข้อความของคุณจะยังคงอยู่ครบ

วันนี้จะได้เวอร์ชันไหน

เมื่อวันที่ 3 พฤศจิกายน 2026 api.meshtastic.org แสดง 2.7.26.54e0d8d และ 2.7.15.567b8ea เป็นรุ่นเสถียร และ 2.8.2.4c89b69 เป็นรุ่นอัลฟาใหม่สุด Mesh+ เปรียบเทียบเฉพาะตัวเลข x.y.z ดังนั้นบิลด์ที่คอมไพล์ใหม่พร้อม commit hash ใหม่จะไม่ขึ้นเตือนให้คุณอัปเดต สำหรับ Heltec Mesh Node T114 แอปจะดาวน์โหลด firmware-heltec-mesh-node-t114-2.7.26.54e0d8d-ota.zip จากเว็บไซต์เฟิร์มแวร์ของ Meshtastic โดยตรง (ได้สถานะ 200 ตอนที่ผมตรวจสอบ) หากอยากอ่านรายละเอียดโปรโตคอลระดับล่างของบูตโหลดเดอร์ อ่านต่อได้ที่ How Mesh+ flashes Meshtastic firmware onto an nRF52 node over a USB cable

USB หรือ Bluetooth

ใช้สายดีกว่าถ้ามี เพราะ USB เสร็จในประมาณหนึ่งนาทีครึ่ง ส่วน Bluetooth ใช้เวลาราว 10 นาที ต้องใช้โทรศัพท์ที่จับคู่ไว้แล้ววางติดกับวิทยุ และต้องเปิดแอปค้างไว้ตลอด หาก Bluetooth หลุดกลางคัน โหนดจะค้างรออยู่ในโหมดอัปเดต แค่เสียบสายแล้วแตะ ลองอีกครั้ง หรือแตะ ติดตั้ง หากคุณออกจากหน้าจอ เฟิร์มแวร์ ไปแล้ว ส่วนผ่าน USB หากการส่งข้อมูลสะดุดหลังจากเข้าโหมดอัปเดต Mesh+ จะลองใหม่เองสูงสุดสามครั้งก่อนยอมแพ้

หากการอัปเดตหยุดกลางคัน

การแฟลชที่ขาดกลางคันไม่ทำให้บอร์ดพัง โหนดแค่รออยู่ในโหมดอัปเดตเพื่อให้คุณทำต่อจนเสร็จ เปิดหน้าจอเชื่อมต่อของ Mesh+ แตะ โหนดค้างอยู่ในโหมดอัปเดตใช่ไหม เสียบสายวิทยุ แล้วกด ติดตั้ง หากบอร์ดไม่ยอมเข้าโหมดอัปเดต ให้ถอดสาย กดปุ่มรีเซ็ตสองครั้งติดกัน เสียบกลับเข้าไปแล้วลองใหม่ โหมดสาธิตให้คุณเปิดดูหน้าจอต่างๆ ได้โดยไม่ต้องมีวิทยุ แต่จะไม่แฟลชอะไรทั้งสิ้น

คำถาม

อัปเดตวิทยุ Meshtastic แบบ ESP32 ด้วย Mesh+ ได้ไหม

ไม่ได้ Mesh+ แฟลชได้เฉพาะบอร์ด nRF52840 อย่าง Heltec Mesh Node T114, RAK WisBlock 4631 และ LILYGO T-Echo สำหรับบอร์ด ESP32 อย่าง Heltec V3 ให้เสียบเข้าคอมพิวเตอร์แล้วใช้ flasher.meshtastic.org

การอัปเดตจะลบข้อความและการตั้งค่าของฉันไหม

ไม่ลบ การตั้งค่า ห้อง และข้อความของคุณจะยังคงอยู่ในโหนด ต่อให้การแฟลชขาดไปกลางทาง โหนดก็จะรออยู่ในโหมดอัปเดตเพื่อให้คุณสั่งแฟลชใหม่ได้

ถ้าโหนดค้างอยู่ในโหมดอัปเดตต้องทำอย่างไร

แตะ โหนดค้างอยู่ในโหมดอัปเดตใช่ไหม ที่หน้าจอเชื่อมต่อ เสียบสายวิทยุ (หรือวางโทรศัพท์ไว้ติดกันหากใช้ Bluetooth) แล้วแตะ ติดตั้ง หากไม่ยอมเข้าโหมดอัปเดต ให้ถอดสาย กดปุ่มรีเซ็ตสองครั้งติดกัน เสียบสายกลับเข้าไปแล้วลองอีกครั้ง

ย้อนกลับไปใช้เฟิร์มแวร์ Meshtastic รุ่นเก่าได้ไหม

ได้ ตัวเลือกเฟิร์มแวร์ แสดงทุกเวอร์ชันที่ Meshtastic เผยแพร่ให้บอร์ดของคุณ รวมถึงเวอร์ชันเก่าด้วย Mesh+ จะเตือนว่าเฟิร์มแวร์รุ่นเก่าอาจติดขัดกับการตั้งค่าที่ใหม่กว่า และชี้ให้คุณใช้ รีเซ็ตการตั้งค่า หากโหนดทำงานแปลกๆ

การอัปเดตเฟิร์มแวร์ Meshtastic ใช้เวลานานแค่ไหน

ประมาณหนึ่งนาทีครึ่งผ่านสาย USB หรือราว 10 นาทีผ่าน Bluetooth โดยเปิดแอปค้างไว้ข้างๆ วิทยุ
