วิธีอัปเดตเฟิร์มแวร์ Meshtastic จากโทรศัพท์

ตรวจเทียบกับซอร์สของ Mesh+ และรายการรุ่นของ Meshtastic เมื่อ 3 พฤศจิกายน 2026

หากวิทยุ Meshtastic ของคุณใช้ชิป nRF52840 เช่น Heltec Mesh Node T114, RAK WisBlock 4631 หรือ LILYGO T-Echo คุณอัปเดตเฟิร์มแวร์จากโทรศัพท์ Android ด้วย Mesh+ ได้ โดยเปิดการตั้งค่าโหนด เลือกเวอร์ชัน แตะติดตั้ง แล้วรอประมาณหนึ่งนาทีครึ่งผ่านสาย USB-C การตั้งค่า ห้อง และข้อความของคุณจะยังอยู่ในโหนด ส่วนบอร์ดที่ใช้ชิป ESP32 เช่น Heltec V3 ให้อัปเดตจากคอมพิวเตอร์ที่ flasher.meshtastic.org

สิ่งที่ต้องมี

  • Mesh+ สำหรับ Android (Google Play หรือ APK) บน Android 12 ขึ้นไป และอินเทอร์เน็ตสำหรับดาวน์โหลด
  • วิทยุที่รันเฟิร์มแวร์ Meshtastic 2.x บนบอร์ด nRF52 หนึ่งใน 39 รุ่นในรายการฮาร์ดแวร์ของ Mesh+ (รวมทั้งหมด 118 บอร์ด)
  • สาย USB-C ที่ส่งข้อมูลได้ หรือวิทยุที่จับคู่ผ่าน Bluetooth ไว้แล้ว

อัปเดตเฟิร์มแวร์ Meshtastic ทีละขั้นตอน

  1. เปิดการตั้งค่าโหนด เชื่อมต่อวิทยุของคุณใน Mesh+ แล้วเปิดการตั้งค่าโหนด การ์ดบอร์ดด้านบนจะแสดงว่า Mesh+ จำบอร์ดรุ่นไหนได้ ชิปอะไร และติดตั้งเฟิร์มแวร์เวอร์ชันใดอยู่ เช่น nRF52840 · Firmware 2.7.15
  2. แตะอัปเดต หรือเปิดตัวเลือกเฟิร์มแวร์ เมื่อ Meshtastic ปล่อยรุ่นเสถียรที่ใหม่กว่าสำหรับบอร์ดรุ่นนี้พอดี การ์ดจะแสดง อัปเดตเป็น ตามด้วยเวอร์ชัน หากไม่มี จะแสดง เป็นเวอร์ชันล่าสุด · ตัวเลือกเฟิร์มแวร์ ซึ่งเปิดหน้าจอเดียวกัน
  3. เลือกเวอร์ชัน หน้าจอเฟิร์มแวร์แสดงทุกเวอร์ชันที่ Meshtastic ปล่อยให้บอร์ดนี้ โดยเรียงจากใหม่สุด และติดป้าย ล่าสุด และ ติดตั้งแล้ว หากต้องการรุ่นอัลฟา ให้เปิดรวมเวอร์ชันทดสอบ ถ้าเลือกเวอร์ชันที่เก่ากว่า จะมีคำเตือนขึ้นก่อน
  4. แตะติดตั้ง Mesh+ จะดาวน์โหลดแพ็กเกจอัปเดตของบอร์ดจากเว็บไซต์เฟิร์มแวร์ของ Meshtastic รีสตาร์ทโหนดเข้าสู่โหมดอัปเดต ขอสิทธิ์ USB ลบเฟิร์มแวร์เก่า แล้วติดตั้งเฟิร์มแวร์ใหม่พร้อมแถบความคืบหน้า
  5. รอการรีสตาร์ท เมื่อแถบเต็ม Mesh+ จะแจ้งว่าโหนดกำลังรีสตาร์ทด้วยเวอร์ชันใหม่ และเชื่อมต่อกลับเองโดยอัตโนมัติ การตั้งค่า ห้อง และข้อความของคุณยังอยู่ครบ

วันนี้จะได้เวอร์ชันไหน

เมื่อ 3 พฤศจิกายน 2026 รายการเฟิร์มแวร์ของ Meshtastic ที่ api.meshtastic.org มี 2.7.26.54e0d8d และ 2.7.15.567b8ea เป็นรุ่นเสถียร และ 2.8.2.4c89b69 เป็นรุ่นอัลฟาล่าสุด Mesh+ เปรียบเทียบเฉพาะส่วน x.y.z ดังนั้นการสร้างรุ่นใหม่ที่ใช้ commit hash ต่างกันจะไม่ปรากฏเป็นการอัปเดต แพ็กเกจอัปเดตที่แอปดาวน์โหลดสำหรับ Heltec Mesh Node T114 คือ firmware-heltec-mesh-node-t114-2.7.26.54e0d8d-ota.zip จากเว็บไซต์เฟิร์มแวร์ของ Meshtastic ซึ่งตอบกลับด้วยสถานะ 200 ตอนที่เราตรวจ ส่วนข้อมูลไปถึงบูตโหลดเดอร์ด้วยวิธีใดนั้น อธิบายไว้ในHow Mesh+ flashes Meshtastic firmware onto an nRF52 node over a USB cable

USB หรือ Bluetooth

สายเป็นวิธีที่เร็วที่สุด ใช้เวลาประมาณหนึ่งนาทีครึ่ง ส่วนผ่าน Bluetooth การอัปเดตแบบเดียวกันใช้เวลาประมาณ 10 นาที ต้องเปิดแอปค้างไว้ และโทรศัพท์ต้องอยู่ใกล้โหนด อีกทั้งต้องใช้โทรศัพท์ที่จับคู่กับโหนดไว้แล้ว หากการอัปเดตผ่าน Bluetooth ถูกขัดจังหวะ โหนดจะรออยู่ในโหมดอัปเดต ให้เสียบสายแล้วแตะลองอีกครั้ง หรือแตะติดตั้งหากออกจากหน้าจอเฟิร์มแวร์ไปแล้ว หากการส่งข้อมูลผ่าน USB สะดุดหลังจากโหนดเข้าสู่โหมดอัปเดตแล้ว Mesh+ จะเริ่มใหม่เองได้สูงสุดสามครั้งก่อนแสดงข้อผิดพลาด

หากการอัปเดตหยุดกลางคัน

การอัปเดตที่ถูกขัดจังหวะจะทิ้งให้โหนดรออยู่ในโหมดอัปเดต และแอปทำให้เสร็จได้ ที่หน้าเชื่อมต่อของ Mesh+ ให้แตะ โหนดค้างอยู่ในโหมดอัปเดตใช่ไหม เสียบโหนด แล้วแตะ ติดตั้ง หากโหนดไม่เข้าสู่โหมดอัปเดตเลย ให้ถอดสาย กดปุ่มรีเซ็ตของโหนดสองครั้งติดกัน เสียบสาย แล้วลองอีกครั้ง หากไม่มีวิทยุเชื่อมต่ออยู่ โหมดสาธิตจะแสดงหน้าจอต่างๆ ให้ดูได้ แต่ติดตั้งอะไรไม่ได้

คำถาม

อัปเดตวิทยุ Meshtastic แบบ ESP32 ด้วย Mesh+ ได้ไหม

ไม่ได้ Mesh+ อัปเดตบอร์ด nRF52840 เช่น Heltec Mesh Node T114, RAK WisBlock 4631 และ LILYGO T-Echo ส่วนบอร์ด ESP32 เช่น Heltec V3 ให้ใช้ flasher.meshtastic.org จากคอมพิวเตอร์

การอัปเดตจะลบข้อความและการตั้งค่าของฉันไหม

ไม่ลบ การตั้งค่า ห้อง และข้อความของคุณจะยังอยู่ในโหนด หากการอัปเดตถูกขัดจังหวะ โหนดจะรออยู่ในโหมดอัปเดต และคุณลองอีกครั้งได้

ถ้าโหนดค้างอยู่ในโหมดอัปเดตต้องทำอย่างไร

ที่หน้าเชื่อมต่อ ให้แตะ โหนดค้างอยู่ในโหมดอัปเดตใช่ไหม เสียบโหนด (หรือถือโทรศัพท์ไว้ใกล้ๆ หากการอัปเดตทำงานผ่าน Bluetooth) แล้วแตะ ติดตั้ง หากโหนดไม่เข้าสู่โหมดอัปเดตเลย ให้ถอดสาย กดปุ่มรีเซ็ตของโหนดสองครั้งติดกัน เสียบสาย แล้วลองอีกครั้ง

ย้อนกลับไปใช้เฟิร์มแวร์ Meshtastic รุ่นเก่าได้ไหม

ได้ ตัวเลือกเฟิร์มแวร์แสดงทุกเวอร์ชันที่ Meshtastic ปล่อยให้บอร์ดของคุณ และคุณเลือกเวอร์ชันที่เก่ากว่าได้ Mesh+ จะเตือนว่าเฟิร์มแวร์รุ่นเก่าอาจไม่เข้าใจการตั้งค่าที่ใหม่กว่า และแนะนำให้ใช้ รีเซ็ตการตั้งค่า หากโหนดทำงานผิดปกติ

การอัปเดตเฟิร์มแวร์ Meshtastic ใช้เวลานานแค่ไหน

ประมาณหนึ่งนาทีครึ่งผ่านสาย USB ส่วนผ่าน Bluetooth ใช้เวลาประมาณ 10 นาที และต้องเปิดแอปค้างไว้โดยให้โทรศัพท์อยู่ใกล้โหนด
