如何用手機更新 Meshtastic 韌體

已對照 Mesh+ 原始碼與 Meshtastic 的版本列表查證，日期為 2026 年 11 月 3 日。

你可以用 Mesh+ 直接在 Android 手機上更新任何採用 nRF52840 晶片的 Meshtastic 無線電（例如 Heltec Mesh Node T114、RAK WisBlock 4631 或 LILYGO T-Echo）。開啟「節點設定」、選擇版本、點選「安裝」，接上 USB-C 線等大約一分半鐘就行。你的設定、聊天室和訊息都會完整保留。像 Heltec V3 這樣的 ESP32 開發板仍然需要電腦和 flasher.meshtastic.org。

你需要準備什麼

  • Android 12 或更新版本上的 Android 版 Mesh+（Google Play 或 APK），以及用來擷取韌體的網際網路連線。
  • 一台執行 Meshtastic 2.x 的無線電，採用 Mesh+ 硬體表中的 39 款 nRF52 開發板之一（硬體表共有 118 款開發板）。
  • 一條可傳輸資料的 USB-C 線，或是已透過藍牙配對好的節點。

逐步更新 Meshtastic 韌體

  1. 開啟「節點設定」。在 Mesh+ 中連接你的無線電，接著前往「節點設定」。頂端的開發板卡片會顯示偵測到的開發板、晶片以及目前執行的韌體，例如 nRF52840 · 韌體 2.7.15。
  2. 點選「更新」或開啟「韌體選項」。如果 Meshtastic 為你的開發板發布了較新的穩定版，卡片會顯示「更新至」加上版本號碼。否則會顯示「已是最新版本 · 韌體選項」，點進去同樣會帶你到版本選擇畫面。
  3. 選擇版本。「韌體」畫面會由新到舊列出 Meshtastic 為你的開發板發布的每個版本，並標示「最新」與「已安裝」。需要 alpha 版本請開啟「預先發行版」；選擇較舊版本時會先跳出警告。
  4. 點選「安裝」。Mesh+ 會從 Meshtastic 的韌體網站下載 zip 檔，讓節點重新啟動進入更新模式，請求 USB 權限，清除舊韌體，並搭配進度列寫入新版本。
  5. 等待重新啟動。進度列跑滿後，節點會重新啟動至新版本，Mesh+ 也會自動重新連線。你的設定、聊天室和訊息都會留在原處。

你現在會拿到哪個版本

2026 年 11 月 3 日，api.meshtastic.org 將 2.7.26.54e0d8d 和 2.7.15.567b8ea 列為穩定版，最新的 alpha 版則是 2.8.2.4c89b69。Mesh+ 只比對 x.y.z 這幾碼數字，所以換了新 commit 雜湊值的重建版本不會一直催你更新。針對 Heltec Mesh Node T114，它會直接從 Meshtastic 的韌體網站下載 firmware-heltec-mesh-node-t114-2.7.26.54e0d8d-ota.zip（我檢查時回應狀態碼 200）。如果你想看底層啟動載入程式協定的細節，請閱讀 Mesh+ 如何透過 USB 線把 Meshtastic 韌體寫入 nRF52 節點。

USB 還是藍牙

手邊有線就盡量用線：USB 大約一分半鐘就能完成，而藍牙大概要花 10 分鐘，除了需要已配對好的手機緊靠在無線電旁，還必須一直保持 App 開啟。如果藍牙在刷寫途中斷線，節點會停在更新模式；請接上線並點選「再試一次」，如果已經離開「韌體」畫面則點選「安裝」。透過 USB 刷寫時，如果進入更新模式後傳輸出現卡頓，Mesh+ 會在放棄前自動重試最多三次。

如果更新進行到一半停了

刷寫中斷不會讓開發板變磚，節點只是停在更新模式等你完成。開啟 Mesh+ 的連線畫面，點選節點卡在更新模式？，接上無線電，再按安裝。如果開發板不願進入更新模式，請拔掉它，連按兩下重置按鈕，重新接上再試一次。示範模式讓你在沒有無線電的情況下瀏覽畫面，但不會真的寫入任何東西。

常見問題

可以用 Mesh+ 更新 ESP32 的 Meshtastic 無線電嗎？

不行。Mesh+ 只會刷寫 nRF52840 開發板，例如 Heltec Mesh Node T114、RAK WisBlock 4631 和 LILYGO T-Echo。像 Heltec V3 這樣的 ESP32 開發板，請接上電腦並使用 flasher.meshtastic.org。

更新會清除我的訊息和設定嗎？

不會。你的設定、聊天室和訊息都會留在節點上。即使刷寫進行到一半中斷，節點也會在更新模式等待，方便你再執行一次。

節點卡在更新模式怎麼辦？

在連線畫面點選「節點卡在更新模式？」，接上無線電（若使用藍牙，則讓手機緊靠在無線電旁），然後點選「安裝」。如果始終沒有進入更新模式，請拔掉它，連按兩下重置按鈕，重新接上後再試一次。

可以退回較舊的 Meshtastic 韌體嗎？

可以。「韌體選項」會顯示 Meshtastic 為你的開發板發布的每個版本，包括較舊的版本。Mesh+ 會提醒你舊版韌體可能難以處理較新的設定，並在節點運作異常時引導你使用「重置設定」。

更新 Meshtastic 韌體要多久？

透過 USB 大約一分半鐘，或是在無線電旁保持 App 開啟的情況下，透過藍牙大約需要 10 分鐘。
