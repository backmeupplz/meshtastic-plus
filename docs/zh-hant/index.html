取得 App

沒有訊號，也能傳訊息給朋友。

Mesh+ 是一款親切好用、專為 Meshtastic 無線電設計的 Android App。把口袋大小的 LoRa 無線電連上手機，你的訊息就能一台接一台地翻山越嶺，沿途不需要基地台、Wi-Fi 或網路。

Mesh+ 免費又開源，大小約 3 MB，需要 Android 12 或更新版本。還沒有無線電嗎？可以先用內建的示範模式逛逛。

發表影片

三十秒看完 Mesh+ 能做什麼。

打開聲音，快速瀏覽私人聊天室、在 Mesh 網路中一跳一跳傳送的訊息、韌體更新和 SMS 轉發。

運作方式

從開箱到傳出第一則訊息，大約只要一分鐘。

Meshtastic 無線電會透過遠距離的 LoRa 無線電互相轉傳訊息，所以範圍內的每一台無線電都成為網路的一部分。Mesh+ 就是讓你的手機與無線電溝通的橋樑。

準備一台 Meshtastic 無線電。

Mesh+ 適用於執行 Meshtastic 韌體 2.x 的無線電，例如 Heltec Mesh Node T114 或 RAK4631。你想聯絡的朋友也需要一台，而中間每一台無線電都能幫忙把訊息傳得更遠。

連接到你的手機。

可以用無線電螢幕上顯示的 PIN 透過藍牙配對，也可以用 USB-C 線接上，讓手機為它供電。Mesh+ 會記住你的無線電，下次只要點一下就能重新連線。

選擇地區和名稱。

全新的無線電在知道該用哪個頻段之前會保持靜默，所以 Mesh+ 只會問你一次，並依照手機所在的國家建議合適的地區。選好你在 Mesh 網路上的名稱，就可以開始聊天了。

聊天

公開聊天、私人聊天室和私訊，都在同一份列表裡。

公開頻道是附近所有人共用的開放聊天室。私人聊天室經過加密，只有你邀請的人才能閱讀；私訊則由無線電韌體提供端對端加密。

  • 訊息下方的勾號會告訴你，訊息已被其他無線電轉發，或是朋友的無線電已經收到。
  • 未讀標記會顯示有哪些新訊息，不需要打擾的聊天室或對象也可以靜音。
  • 連線期間，Mesh+ 會在背景持續執行，有新訊息時通知你。
SMS 轉發

只要有一支手機有訊號，整個群組都能傳簡訊。

在深山野外，常常只有一個人，也許是在營地或山稜上，才有一格行動網路訊號。把那支手機設為轉發手機，Mesh 網路上的每個人都能透過它收發一般的簡訊。

  1. 基地台連到一支手機。
  2. Base Camp 的手機有訊號，負責執行轉發。
  3. 無線電在 Mesh 網路中接力傳送簡訊。
  4. 你的手機沒有訊號，只有一台無線電。

簡訊和來電會出現在私人聊天室。

轉發手機收到的每一則 SMS，以及來電和未接來電，都會發到你選定的私人聊天室，Mesh+ 會以大家熟悉的簡訊對話串顯示。

聊天室裡的任何人都能回覆簡訊。

滑動簡訊即可回覆，也可以點 SMS 按鈕寫給任何號碼或聯絡人。轉發手機會用自己的號碼寄出，寄出後會出現一個勾號。

使用其他 Meshtastic App 的朋友也能加入。

轉發的訊息是純文字，所以使用其他 Meshtastic App 的人也能閱讀，並輸入 /sms +15551234567 your message 來傳簡訊。

轉發聊天室裡的每個人都能閱讀那支手機收到的簡訊，也能用它的號碼傳送 SMS，所以請只讓信任的人加入聊天室。簡訊依電信業者的一般費率計費。

開啟只要幾秒鐘。

在有訊號的那支手機上，開啟「設定」，進入「SMS 轉發」，選擇一個私人聊天室（或讓 Mesh+ 建立一個名為 Relay 的聊天室），然後開啟。Android 會一次詢問 SMS 和電話的存取權限，轉發執行期間會一直顯示一則通知。

轉發功能在你開啟之前都是關閉的，也隨時可以在同一個畫面關閉。

邀請

用 QR Code 或連結邀請朋友加入私人聊天室。

只要點幾下就能建立聊天室，並以 QR Code 讓對方掃描，或把連結在出發前傳給對方。Mesh+ 使用標準的 Meshtastic 邀請格式，所以 Meshtastic 官方 App 的連結能在 Mesh+ 開啟，你的連結也能在官方 App 開啟。

  • 每個私人聊天室都有自己的加密金鑰，沒有邀請的人即使他們的無線電會幫忙轉傳，也讀不到內容。
  • 加入只要掃描 QR Code 或貼上連結，退出只要點一下。
節點

看見你的節點聽得到的每一台無線電。

「節點」分頁會列出你的無線電收到過的所有節點，最愛排在最上面，過去兩小時內收到訊號的節點會有線上標記。點一下節點，就能看到上次收到的時間、距離幾跳、訊號強弱和剩餘電量，還能傳訊息給它，或加入最愛；最愛會儲存在你的無線電上。

無線電設定

每項設定都用淺顯的文字說明用途。

角色、轉發、無線電預設組合、跳數上限、發射功率、位置分享、省電、螢幕和藍牙配對，都只要點一下就能設定，而且每一項都附有簡短說明，告訴你它的作用以及何時需要調整。Mesh+ 會一次儲存你的所有變更，所以無線電只會重新啟動一次。

  • 頁面頂端會顯示你的無線電是哪一種開發板、執行的韌體版本和電量。
  • 遇到狀況時，你可以清除節點列表、在保留身分的情況下重置設定，或是完整回復原廠設定。
韌體

不用電腦，也能更新無線電的韌體。

Meshtastic 發布新的穩定版時，Mesh+ 會直接在無線電的設定中提供更新。Heltec T114 和 RAK4631 這類 nRF52 開發板，用 USB 線大約一分鐘就能更新；不想接線的話，透過藍牙大約十分鐘。

  • 你可以選擇任何已發布的版本，包括預先發行版，也可以退回較舊的版本。
  • 你的設定、聊天室和訊息都會保留，卡在更新模式的無線電也可以從連線畫面救回來。
  • ESP32 開發板請用電腦到 flasher.meshtastic.org 更新。
更多功能

連小地方也都照顧到了。

你所有的無線電，只要點一下。

從頂端列就能在不同無線電之間切換，並看到每一台是哪種開發板、執行的韌體版本和電量。

沒有無線電也能試用。

內建的示範模式會模擬一台無線電，包含聊天室、私訊、回覆和設定，讓你在買硬體之前先四處看看。

太吵的聊天室可以靜音。

任何聊天室或私訊都能靜音，聊天列表中劃掉的鈴鐺圖示會提醒你哪些是安靜的。

你的訊息只屬於你。

沒有帳號、廣告或分析工具，你的訊息紀錄只儲存在你的手機上。

程式碼是開源的。

Mesh+ 在 GitHub 上公開開發，任何人都能閱讀程式碼、自行建置，並提出改進。

一條線就能為無線電供電。

透過 USB-C，手機也會為無線電供電，所以即使無線電沒有電池，也能繼續運作。

你需要準備什麼

Mesh+ 需要的東西很少。

任何 Android 12 或更新版本的手機都可以。Mesh+ 大小約 3 MB，也不需要帳號。
你的無線電需要 Meshtastic 韌體 2.x。這類無線電都能透過藍牙連線；透過 USB 連線時，Mesh+ 已用 Heltec T114 這類 nRF52 開發板測試過。
你的朋友也需要無線電。他們可以使用 Mesh+ 或任何其他 Meshtastic App，範圍內的每一台無線電都能擴大 Mesh 網路。
常見問題

以下是大家最常問的問題。

需要行動網路或網際網路嗎？

不需要。訊息是透過 LoRa 在 Meshtastic 無線電之間傳送，所以只要你們的無線電互相收得到，就能聊天。Mesh+ 只有在檢查和下載韌體更新時才會連上網路。

訊息可以傳多遠？

兩台手持無線電在視線清楚的情況下，通常可以相隔好幾公里互相連線，中間的每一台無線電也都能把訊息再往前傳。山丘、建築物和樹木會縮短距離，所以大家都喜歡把中繼站架在高處。

可以和使用 Meshtastic 官方 App 的人聊天嗎？

可以。Mesh+ 使用相同的通訊協定，所以不論用哪個 App，同一個頻道的所有人都看得到彼此的訊息，聊天室邀請連結也能雙向通用。

誰能讀到經過 SMS 轉發的簡訊？

轉發聊天室裡的每個人都能讀到轉發手機收到的簡訊和來電，也能用它的號碼傳送簡訊。聊天室經過加密，所以外人看不到，但請謹慎挑選成員。我們不會收到任何內容，也不會傳送給任何伺服器。

Mesh+ 有上架 Google Play 或 F-Droid 嗎？

Mesh+ 已在 Google Play 上架，F-Droid 也即將推出。你也可以從這個頁面安裝 APK：在手機上開啟檔案，Android 詢問時，允許瀏覽器安裝 App 即可。

有 iPhone 版本嗎？

目前 Mesh+ 只有 Android 版。使用 iPhone 的朋友可以用 Meshtastic 官方 App 加入你的聊天室。

Mesh+ 要付費嗎？

不用。Mesh+ 免費又開源，沒有帳號、廣告、分析工具或 App 內購買。
