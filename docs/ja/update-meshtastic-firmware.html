スマートフォンでMeshtasticファームウェアを更新する方法

Mesh+のソースコードとMeshtasticのリリース一覧で、2026年11月3日に確認しました。

お使いのMeshtastic無線機がnRF52840チップを搭載している場合（Heltec Mesh Node T114、RAK WisBlock 4631、LILYGO T-Echoなど）は、AndroidスマートフォンのMesh+からファームウェアを更新できます。ノード設定を開いてバージョンを選び、「インストール」をタップして、USB-Cケーブルで約1分半待つだけです。設定、ルーム、メッセージはノードに残ります。Heltec V3のようにESP32チップを搭載したボードは、パソコンからflasher.meshtastic.orgで更新します。

用意するもの

  • Android向けのMesh+（Google PlayまたはAPK）。Android 12以降で、ダウンロード用にインターネットに接続できる環境が必要です。
  • Meshtasticファームウェア2.xが動作し、Mesh+のハードウェア一覧（全118ボード）にある39のnRF52ボードのいずれかである無線機。
  • データ通信に対応したUSB-Cケーブル、またはBluetoothでペアリング済みの無線機。

Meshtasticファームウェアを更新する手順

  1. ノード設定を開きます。Mesh+で無線機に接続し、ノード設定を開きます。上部のボードカードには、Mesh+が認識したボード、そのチップ、インストール済みのファームウェアが表示されます（例：nRF52840 · ファームウェア 2.7.15）。
  2. 「アップデート」またはファームウェアのオプションをタップします。お使いのボード専用に、Meshtasticがより新しい安定版を公開しているときは、カードに「にアップデート」とバージョンが表示されます。そうでないときは「最新です · ファームウェアのオプション」と表示され、これをタップすると同じ画面が開きます。
  3. バージョンを選びます。ファームウェア画面には、そのボード向けにMeshtasticが公開しているすべてのバージョンが新しい順に並び、「最新」や「インストール済み」のタグが付きます。アルファ版を使いたいときは、プレリリースをオンにします。古いバージョンを選ぶと、先に警告が表示されます。
  4. 「インストール」をタップします。Mesh+は、Meshtasticのファームウェアサイトからそのボード用のアップデートパッケージをダウンロードし、ノードをアップデートモードで再起動して、USBの許可を求め、古いファームウェアを消去してから、進行状況バーを表示しながら新しいファームウェアをインストールします。
  5. 再起動を待ちます。バーが最後まで進むと、Mesh+に、ノードが新しいバージョンで再起動していることが表示され、自動的に再接続されます。設定、ルーム、メッセージはそのまま残っています。

今、入手できるバージョン

2026年11月3日の時点で、api.meshtastic.orgにあるMeshtasticのファームウェア一覧では、安定版として2.7.26.54e0d8dと2.7.15.567b8ea、最新のアルファ版として2.8.2.4c89b69が公開されていました。Mesh+が比較するのはx.y.zの部分だけなので、コミットハッシュが違うだけの再ビルドが更新として表示されることはありません。Heltec Mesh Node T114用にダウンロードするアップデートパッケージは、Meshtasticのファームウェアサイトにあるfirmware-heltec-mesh-node-t114-2.7.26.54e0d8d-ota.zipで、確認した時点ではステータス200が返ってきました。このデータがどのようにブートローダーへ届くのかは、How Mesh+ flashes Meshtastic firmware onto an nRF52 node over a USB cableで解説しています。

USBかBluetoothか

速いのはケーブルで、約1分半です。Bluetoothでは同じ更新に約10分かかり、アプリを開いたままスマートフォンをノードの近くに置いておく必要があり、ノードがすでにペアリングされているスマートフォンでなければ行えません。Bluetoothでの更新が中断された場合、ノードはアップデートモードで待機します。ケーブルをつないで「再試行」をタップしてください。ファームウェア画面を離れてしまった場合は「インストール」をタップします。ノードがアップデートモードに入ったあとでUSBの転送が途切れても、Mesh+は自動的にやり直し、エラーを表示するまでに合計で最大3回まで試みます。

更新が途中で止まったときは

更新が中断されると、ノードはアップデートモードで待機したままになりますが、アプリで最後まで完了できます。Mesh+の接続画面でノードがアップデートモードのままですか？をタップし、ノードをケーブルでつないでインストールをタップしてください。ノードがアップデートモードにまったく入らない場合は、ケーブルを抜き、リセットボタンを2回すばやく押してから、ケーブルをつないで、もう一度お試しください。無線機を接続していないときは、デモモードで画面を見られますが、何かをインストールすることはできません。

よくある質問

ESP32のMeshtastic無線機をMesh+で更新できますか？

いいえ。Mesh+で更新できるのは、Heltec Mesh Node T114、RAK WisBlock 4631、LILYGO T-EchoなどのnRF52840ボードです。Heltec V3のようなESP32ボードは、パソコンからflasher.meshtastic.orgを使ってください。

更新すると、メッセージや設定は消えますか？

いいえ。設定、ルーム、メッセージはノードに残ります。更新が中断された場合、ノードはアップデートモードで待機するので、もう一度お試しいただけます。

ノードがアップデートモードのままになったときは？

接続画面で「ノードがアップデートモードのままですか？」をタップし、ノードをケーブルでつないで（Bluetoothで更新していた場合は、スマートフォンを近くに置いたまま）「インストール」をタップしてください。ノードがアップデートモードに入らない場合は、ケーブルを抜き、リセットボタンを2回すばやく押してから、ケーブルをつないで、もう一度お試しください。

古いMeshtasticファームウェアに戻せますか？

はい。ファームウェアのオプションには、お使いのボード向けにMeshtasticが公開しているすべてのバージョンが並ぶので、古いものも選べます。古いファームウェアは新しい設定を認識できない場合があることをMesh+がお知らせし、ノードの動作がおかしいときは「設定をリセット」を使うよう案内します。

Meshtasticファームウェアの更新にはどのくらいかかりますか？

USBケーブルなら約1分半です。Bluetoothでは約10分かかり、アプリを開いたまま、スマートフォンをノードの近くに置いておく必要があります。
