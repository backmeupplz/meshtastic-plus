スマートフォンでMeshtasticファームウェアを更新する方法

Mesh+のソースコードとMeshtasticのリリース一覧で、2026年11月3日に確認しました。

nRF52840を搭載したMeshtastic無線機（Heltec Mesh Node T114、RAK WisBlock 4631、LILYGO T-Echoなど）なら、AndroidスマートフォンのMesh+から直接ファームウェアを更新できます。ノード設定を開いてバージョンを選び、「インストール」をタップして、USB-Cケーブルで1分半ほど待つだけです。設定、ルーム、メッセージはそのまま残ります。Heltec V3のようなESP32ボードには、引き続きパソコンとflasher.meshtastic.orgが必要です。

用意するもの

  • Android 12以降で動くAndroid版Mesh+（Google PlayまたはAPK）と、ファームウェアを取得するためのインターネット接続。
  • Meshtastic 2.xで動作し、Mesh+のハードウェア一覧（全118ボード）に含まれる39種類のnRF52ボードのいずれかを搭載した無線機。
  • データ通信に対応したUSB-Cケーブル、またはBluetoothでペアリング済みのノード。

Meshtasticファームウェアを更新する手順

  1. ノード設定を開きます。Mesh+で無線機に接続してノード設定を開きます。上部のボードカードに、認識されたボード、チップ、動作中のファームウェアが表示されます（例：nRF52840 · ファームウェア 2.7.15）。
  2. アップデートをタップするか、ファームウェアのオプションを開きます。お使いのボード向けにMeshtasticの新しい安定版が出ている場合、カードにはバージョン番号と「〜にアップデート」が表示されます。そうでない場合は「最新です · ファームウェアのオプション」と表示され、タップすると同じ選択画面が開きます。
  3. バージョンを選びます。ファームウェア画面には、お使いのボード向けにMeshtasticが公開しているすべてのリリースが新しい順に並び、「最新」や「インストール済み」のタグが付きます。アルファ版を使いたいときはプレリリースをオンにしてください。古いバージョンを選ぶと、先に警告が表示されます。
  4. 「インストール」をタップします。Mesh+がMeshtasticのファームウェアサイトからzipファイルを取得し、ノードをアップデートモードで再起動してUSBの許可を求め、古いファームウェアを消去したあと、進行状況バーを表示しながら新しいビルドを書き込みます。
  5. 再起動を待ちます。バーが最後まで進むと、ノードが新しいバージョンで再起動し、Mesh+が自動で再接続します。設定、ルーム、メッセージはそのまま残ります。

今、入手できるバージョン

2026年11月3日の時点で、api.meshtastic.orgには安定版として2.7.26.54e0d8dと2.7.15.567b8ea、最新のアルファ版として2.8.2.4c89b69が掲載されていました。Mesh+はx.y.zの数字だけを比較するため、コミットハッシュが変わっただけの再ビルドで更新を促されることはありません。Heltec Mesh Node T114の場合、Meshtasticのファームウェアサイトからfirmware-heltec-mesh-node-t114-2.7.26.54e0d8d-ota.zipを直接ダウンロードします（私が確認した時点ではステータス200が返りました）。ブートローダーの低レベルなプロトコルの詳細を知りたい方は、How Mesh+ flashes Meshtastic firmware onto an nRF52 node over a USB cableをご覧ください。

USBかBluetoothか

ケーブルがあるならUSBを使うのがおすすめです。USBなら1分半ほどで終わりますが、Bluetoothでは約10分かかり、ペアリング済みのスマートフォンを無線機のすぐそばに置いてアプリを開いたままにする必要があります。書き込みの途中でBluetoothが切れても、ノードはアップデートモードで待機するので、ケーブルをつないで「再試行」をタップしてください（ファームウェア画面を離れた場合は「インストール」をタップします）。USBでは、アップデートモードに入ったあとに転送がつまずいても、Mesh+が自動で最大3回までやり直してからエラーにします。

更新が途中で止まったときは

書き込みが途中で止まってもボードが壊れることはなく、ノードはアップデートモードで続きを待っています。Mesh+の接続画面を開いてノードがアップデートモードのままですか？をタップし、無線機をケーブルでつないでインストールをタップしてください。ボードがアップデートモードに入らないときは、ケーブルを抜き、リセットボタンを2回すばやく押してから、もう一度つないでやり直してください。無線機がなくてもデモモードで画面を見て回れますが、書き込みは行われません。

よくある質問

ESP32のMeshtastic無線機をMesh+で更新できますか？

いいえ。Mesh+で書き込めるのは、Heltec Mesh Node T114、RAK WisBlock 4631、LILYGO T-EchoといったnRF52840ボードだけです。Heltec V3のようなESP32ボードは、パソコンにつないでflasher.meshtastic.orgを使ってください。

更新すると、メッセージや設定は消えますか？

いいえ。設定、ルーム、メッセージはノードに残ります。書き込みが途中で切れても、ノードはアップデートモードで待機しているので、そのままやり直せます。

ノードがアップデートモードのままになったときは？

接続画面で「ノードがアップデートモードのままですか？」をタップし、無線機をケーブルでつないで（Bluetoothの場合はスマートフォンをすぐそばに置いて）「インストール」をタップしてください。アップデートモードに入らない場合は、ケーブルを抜き、リセットボタンを2回すばやく押してから、もう一度つないで再試行してください。

古いMeshtasticファームウェアに戻せますか？

はい。ファームウェアのオプションには、お使いのボード向けにMeshtasticが公開しているすべてのバージョンが古いものも含めて表示されます。Mesh+からは、古いファームウェアは新しい設定をうまく扱えない場合があるとの警告が出て、ノードの動作がおかしいときは「設定をリセット」を使うよう案内されます。

Meshtasticファームウェアの更新にはどのくらいかかりますか？

USBなら約1分半、Bluetoothなら無線機のそばでアプリを開いたままにして約10分かかります。
