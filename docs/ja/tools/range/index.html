Meshtastic 通信距離・リンクバジェット計算ツール

デフォルトのLong Fastプリセットを使うMeshtastic無線機は、郊外でおおよそ1.5〜3.8 km、開けた農村部で4〜10 km、遮るものがなければ山頂間で100 km以上届きます。下でモデムプリセット、送信出力、アンテナ、ケーブル損失、地形を選ぶと、リンクバジェット、フェードマージン、現実的な通信距離の目安をブラウザ上で計算できます。

どんなリンクバジェット計算式よりも地形が勝る理由

LoRa受信機は-131 dBmというノイズの底からLong Fastのパケットを拾い上げることができ、一般的な22 dBm無線機で150 dBを超えるリンクバジェットが得られます。906.875 MHzの自由空間なら、150 dBあれば数百キロメートル先まで届きます。meshtastic.orgに記録されている地上間331 kmのMeshtastic最長記録も、遮蔽物のまったくない高い山頂に置いた2台のRAK4631ノードによる見通し通信で達成されました。

ところが地上に降りると、デシベルを使い切るはるか前に3つの物理的な壁が立ちはだかります。1つ目は地球の丸みです。平地で目線の高さ1.8 mに無線機を持った2人の無線見通し距離は、地面そのものが間にせり上がるまでの約11 kmしかありません。2つ目は第1フレネルゾーン、つまりアンテナ間を結ぶ直線の周りにラグビーボール状に広がる空間です。906.875 MHzで距離3 kmの場合、中間点の半径は15.8 mになり、目視で向こうの丘が見えていてもこの領域のおよそ40%以上が遮られると余分な減衰が生じます。3つ目は遮蔽物です。レンガの壁、鉄骨の屋根、険しい丘、雨に濡れた樹木は868 MHzや915 MHzの電波を素早く吸収します。見晴らし台から40 km届く同じ無線機が、都心のマンション街では800メートル越えるのにも苦労するのはそのためです。

Meshtasticのモデムプリセットと公開リンクバジェット

数値の算出方法と近似になる部分

RF計算の厳密な部分はリンクバジェットの基本式そのままです。Meshtasticが公開しているプリセットのリンクバジェットは送信出力22 dBm・0 dBiアンテナを前提としているため、本ツールは各プリセットの受信感度をRX_sens = 22 - LinkBudget_refとして逆算し、設定した構成のリンクバジェットをTX_dBm + TX_gain + RX_gain - Cable_loss - RX_sensで求めます。距離d（km）、周波数f（MHz）での自由空間経路損失は32.44 + 20 * log10(d) + 20 * log10(f)、中間点における第1フレネルゾーンの半径（m）は17.32 * sqrt(d / (4 * f_GHz))です。

地形別の通信距離レンジはあくまで近似値です。「見通しあり」では自由空間式をフェードマージン20 dB（控えめ）と10 dB（楽観的）で解いていますが、これは両ノードが水平線とフレネルゾーンを確保できる十分な高さにある場合にのみ当てはまります。農村・郊外・高密度市街地では、1メートル時点の自由空間損失（L0）を基準にした標準的な対数距離経路損失モデルにフェードマージン10 dBを加え、経路損失指数として樹木が点在する農村部でn = 2.8 to 3.1、郊外でn = 3.2 to 3.6、建物が密集する市街地でn = 3.7 to 4.2を用いています。個別の標高断面、現地のRFノイズフロア、アンテナのSWR不整合、マルチパスフェージングはモデルに含まれていないため、見通し外の距離レンジは概算の計画目安として扱い、屋根や尾根に常設ノードを設置する前は必ず標高プロファイルを確認してください。

計算例

よくある4つの構成を計算ツールに通してみると、数デシベルの出力差よりも周囲の環境がどれほど大きく通信距離を左右するかが見えてきます。

  • 郊外のハンディ機2台・Long Fast（米国 906.875 MHz）：22 dBm、両端2 dBiアンテナ、損失合計1 dBでリンクバジェットは156.0 dB（受信感度-131.0 dBm）です。距離3 kmでの自由空間経路損失は101.1 dB（自由空間マージン+54.9 dB）、フレネル半径は15.8 mとなり、郊外の遮蔽を考慮すると推定通信距離は1.5〜3.8 km（3 kmでの地形マージンは-0.8〜+13.1 dB）に絞られます。
  • 混雑した都市部のメッシュ・Medium Fast（米国 906.875 MHz）：Long FastからMedium Fastへ切り替えると、リンクバジェットは5 dB下がる（合計151.0 dB、受信感度-126.0 dBm）代わりにデータレートが3倍以上（3.52 kbps対1.07 kbps）になります。建物が密集する市街地での推定範囲は0.4〜0.9 kmです。
  • 欧州の農村部・Long Moderate（EU 869.525 MHz）：22 dBm、3 dBiアンテナ、損失1.5 dBでリンクバジェットは160.5 dB（受信感度-134.0 dBm）となり、農村部での推定範囲は7.0〜18.2 km、距離8 kmでのマージンは+8.3〜+20.0 dBです。
  • 山頂の中継器からハンディ機へ（Long Fast、906.875 MHz、見通しあり）：22 dBm、山頂に5.8 dBiマストアンテナ、ハンディ機に2 dBiホイップ、同軸損失2 dBでリンクバジェットは158.8 dBです。見通しが確保された40 kmでは自由空間経路損失が123.6 dBとなり、中間点のフレネル半径57.5 mを遮らなければ+35.2 dBの余裕が残ります。

よくある質問

Meshtastic無線機は実際にどのくらい遠くまで届きますか？

Long Fast、22 dBm、標準2 dBiアンテナの組み合わせでは、高密度な市街地でおおよそ0.4〜1.2 km、郊外で1.5〜3.8 km、開けた農村部で4〜10 km、遮蔽物のない高い尾根同士なら数十〜数百キロメートル届くのが一般的です。

送信出力を2倍にすると、Meshtasticの通信距離も2倍になりますか？

いいえ。送信出力を2倍にしてもリンクバジェットは3 dB増えるだけで、自由空間での距離は約41%、建物や木のある郊外ではおよそ20〜25%しか伸びません。出力を上げるよりも、見通しのよい高い位置にアンテナを置くほうがほとんどの場合で効果的です。

最も遠くまで届くMeshtasticのモデムプリセットはどれですか？

Meshtastic 2.8の汎用プリセット9種類では、Long Moderateの公開リンクバジェット156 dB（Long Fastより3 dB上）が最大ですが、通信速度は0.34 kbpsと遅くなります。通信量の多い都市部のメッシュでは、パケットがチャンネルを占有する時間が短いMedium Fast（148 dB、3.52 kbps）のほうがメッセージが届きやすいことがよくあります。

高利得アンテナのほうが屋内や山間部で性能が落ちることがあるのはなぜですか？

高利得の無指向性アンテナは、エネルギーを水平方向に平たく薄く集中させます。中継器の下にある急な尾根を登っているときや、ザックの中で無線機が斜めになっているときは、ビームが狭いせいで相手ノードを外してしまい、2〜3 dBiのアンテナならつながる場面でも途切れることがあります。

Mesh+でMeshtastic無線機のチャットを始めよう

Mesh+は、広告なし・約3 MBのMITライセンス無料Meshtasticアプリ（Android・iPhone対応）です。公開チャンネル、暗号化されたルーム、ダイレクトメッセージをひとつの一覧にまとめ、無線プリセットをわかりやすい言葉で設定でき、AndroidからはUSBでnRF52のファームウェア更新も行えます。
