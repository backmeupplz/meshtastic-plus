Cara memperbarui firmware Meshtastic dari ponsel

Diperiksa terhadap kode sumber Mesh+ dan daftar rilis Meshtastic pada 3 November 2026.

Anda bisa memperbarui radio Meshtastic nRF52840 mana pun (seperti Heltec Mesh Node T114, RAK WisBlock 4631, atau LILYGO T-Echo) langsung dari ponsel Android dengan Mesh+. Buka Pengaturan node, pilih versi, ketuk Instal, lalu tunggu sekitar satu setengah menit lewat kabel USB-C. Pengaturan, ruang, dan pesan Anda tetap utuh. Board ESP32 seperti Heltec V3 masih memerlukan komputer dan flasher.meshtastic.org.

Yang Anda butuhkan

  • Mesh+ untuk Android (Google Play atau APK) di Android 12 atau lebih baru, ditambah akses internet untuk mengambil firmware.
  • Radio dengan Meshtastic 2.x yang memakai salah satu dari 39 board nRF52 dalam tabel perangkat keras Mesh+ (total 118 board).
  • Kabel data USB-C, atau node yang sudah dipasangkan lewat Bluetooth.

Memperbarui firmware Meshtastic langkah demi langkah

  1. Buka Pengaturan node. Hubungkan radio Anda di Mesh+ lalu masuk ke Pengaturan node. Kartu board di bagian atas menampilkan board yang terdeteksi, chip-nya, dan firmware yang sedang berjalan, misalnya nRF52840 · Firmware 2.7.15.
  2. Ketuk Perbarui atau buka Opsi firmware. Jika Meshtastic punya rilis stabil yang lebih baru untuk board Anda, kartu menampilkan Perbarui ke diikuti nomor versinya. Jika tidak, tertulis Terbaru · opsi firmware, yang membawa Anda ke pemilih versi yang sama.
  3. Pilih versinya. Layar Firmware mencantumkan setiap rilis yang diterbitkan Meshtastic untuk board Anda, dari yang terbaru, dengan label terbaru dan terpasang. Nyalakan pra-rilis untuk build alpha; memilih versi lebih lama akan memunculkan peringatan terlebih dahulu.
  4. Ketuk Instal. Mesh+ mengambil file zip dari situs firmware Meshtastic, memulai ulang node ke mode pembaruan, meminta izin USB, menghapus firmware lama, lalu mem-flash build baru dengan bilah kemajuan.
  5. Tunggu hingga dimulai ulang. Begitu bilahnya penuh, node memulai ulang ke versi baru dan Mesh+ tersambung kembali dengan sendirinya. Pengaturan, ruang, dan pesan Anda tetap aman.

Versi yang Anda dapatkan saat ini

Pada 3 November 2026, api.meshtastic.org mencantumkan 2.7.26.54e0d8d dan 2.7.15.567b8ea sebagai rilis stabil, serta 2.8.2.4c89b69 sebagai alpha terbaru. Mesh+ hanya membandingkan angka x.y.z, jadi build ulang dengan hash commit baru tidak akan terus mengingatkan Anda untuk memperbarui. Untuk Heltec Mesh Node T114, aplikasi mengunduh firmware-heltec-mesh-node-t114-2.7.26.54e0d8d-ota.zip langsung dari situs firmware Meshtastic (mengembalikan status 200 saat saya periksa). Jika Anda ingin detail protokol bootloader tingkat rendah, baca Cara Mesh+ mem-flash firmware Meshtastic ke node nRF52 lewat kabel USB.

USB atau Bluetooth

Gunakan kabel jika ada: USB selesai dalam sekitar satu setengah menit, sedangkan Bluetooth memakan waktu kira-kira 10 menit, butuh ponsel yang sudah dipasangkan tepat di sebelah radio, dan mengharuskan aplikasi tetap terbuka. Jika Bluetooth terputus di tengah flash, node tetap berada di mode pembaruan; colokkan lalu ketuk Coba lagi, atau ketuk Instal jika Anda sudah meninggalkan layar Firmware. Lewat USB, jika transfer tersendat setelah masuk mode pembaruan, Mesh+ mencoba ulang sendiri hingga tiga kali sebelum menyerah.

Jika pembaruan berhenti di tengah jalan

Flash yang terputus tidak akan merusak board; node hanya menunggu di mode pembaruan agar Anda menyelesaikannya. Buka layar sambungan Mesh+, ketuk Node macet di mode pembaruan?, colokkan radio, lalu ketuk Instal. Jika board tidak mau masuk ke mode pembaruan, cabut, tekan tombol reset-nya dua kali, colokkan kembali, lalu coba lagi. Mode demo memungkinkan Anda melihat-lihat layarnya tanpa radio, meski tidak bisa mem-flash apa pun.

Pertanyaan

Bisakah saya memperbarui radio Meshtastic ESP32 dengan Mesh+?

Tidak. Mesh+ hanya mem-flash board nRF52840 seperti Heltec Mesh Node T114, RAK WisBlock 4631, dan LILYGO T-Echo. Untuk board ESP32 seperti Heltec V3, colokkan ke komputer dan gunakan flasher.meshtastic.org.

Apakah pembaruan akan menghapus pesan dan pengaturan saya?

Tidak. Pengaturan, ruang, dan pesan Anda tetap tersimpan di node. Kalaupun proses flash terputus di tengah jalan, node menunggu di mode pembaruan sehingga Anda bisa menjalankannya lagi.

Bagaimana jika node macet di mode pembaruan?

Ketuk Node macet di mode pembaruan? di layar sambungan, colokkan radio (atau dekatkan ponsel tepat di sampingnya untuk Bluetooth), lalu ketuk Instal. Jika tidak kunjung masuk ke mode pembaruan, cabut, tekan tombol reset dua kali, colokkan kembali, lalu coba lagi.

Bisakah saya kembali ke firmware Meshtastic yang lebih lama?

Bisa. Opsi firmware menampilkan semua versi yang diterbitkan Meshtastic untuk board Anda, termasuk versi lama. Mesh+ memperingatkan bahwa firmware lebih lama mungkin bermasalah dengan pengaturan yang lebih baru, dan mengarahkan Anda ke Reset pengaturan jika node bertingkah aneh.

Berapa lama pembaruan firmware Meshtastic berlangsung?

Sekitar satu setengah menit lewat USB, atau sekitar 10 menit lewat Bluetooth dengan aplikasi tetap terbuka di sebelah radio.
