휴대폰으로 Meshtastic 펌웨어 업데이트하는 방법

Mesh+ 소스와 Meshtastic 릴리스 목록을 2026년 11월 3일에 확인했습니다.

Heltec Mesh Node T114, RAK WisBlock 4631, LILYGO T-Echo 같은 nRF52840 Meshtastic 무전기라면 Mesh+로 Android 휴대폰에서 바로 업데이트할 수 있습니다. 노드 설정을 열고 버전을 고른 다음 설치를 탭하고, USB-C 케이블로 연결한 채 약 1분 30초만 기다리면 됩니다. 설정, 채팅방, 메시지는 그대로 유지됩니다. Heltec V3 같은 ESP32 보드는 여전히 컴퓨터와 flasher.meshtastic.org가 필요합니다.

준비물

  • Android 12 이상에서 실행되는 Android용 Mesh+(Google Play 또는 APK)와 펌웨어를 받아 올 인터넷 연결.
  • Mesh+ 하드웨어 표(전체 118종)에 포함된 39종의 nRF52 보드 중 하나를 쓰며 Meshtastic 2.x가 실행 중인 무전기.
  • USB-C 데이터 케이블, 또는 Bluetooth로 이미 페어링된 노드.

Meshtastic 펌웨어 업데이트, 단계별 안내

  1. 노드 설정을 엽니다. Mesh+에서 무전기를 연결하고 노드 설정으로 이동합니다. 맨 위의 보드 카드에 감지된 보드와 칩, 실행 중인 펌웨어가 nRF52840 · 펌웨어 2.7.15처럼 표시됩니다.
  2. 업데이트를 탭하거나 펌웨어 옵션을 엽니다. Meshtastic에 내 보드용으로 더 새로운 안정 빌드가 있으면 카드에 ‘버전(으)로 업데이트’처럼 버전 번호와 함께 표시됩니다. 그렇지 않으면 최신 상태 · 펌웨어 옵션이 표시되며, 이를 탭해도 같은 선택 화면으로 이동합니다.
  3. 버전을 고릅니다. 펌웨어 화면에는 Meshtastic이 내 보드용으로 공개한 모든 릴리스가 최신순으로 나열되며, 최신과 설치됨 태그가 붙습니다. 알파 빌드가 필요하면 프리릴리스를 켜세요. 이전 빌드를 고르면 먼저 경고가 나타납니다.
  4. 설치를 탭합니다. Mesh+가 Meshtastic 펌웨어 사이트에서 zip 파일을 받아 오고, 노드를 업데이트 모드로 다시 시작한 뒤 USB 권한을 요청하며, 이전 펌웨어를 지운 다음 진행 막대와 함께 새 빌드를 플래싱합니다.
  5. 재시작을 기다립니다. 진행 막대가 다 차면 노드가 새 버전으로 다시 시작되고 Mesh+가 알아서 다시 연결합니다. 설정, 채팅방, 메시지는 그대로 남습니다.

지금 받을 수 있는 버전

2026년 11월 3일 기준으로 api.meshtastic.org에는 안정 릴리스로 2.7.26.54e0d8d와 2.7.15.567b8ea가, 가장 새로운 알파로 2.8.2.4c89b69가 올라와 있었습니다. Mesh+는 x.y.z 숫자만 비교하므로 커밋 해시만 바뀐 재빌드 때문에 업데이트하라고 성가시게 뜨지 않습니다. Heltec Mesh Node T114의 경우 Meshtastic 펌웨어 사이트에서 firmware-heltec-mesh-node-t114-2.7.26.54e0d8d-ota.zip을 바로 내려받습니다(제가 확인했을 때 상태 200을 반환했습니다). 저수준 부트로더 프로토콜의 세부 내용이 궁금하다면 How Mesh+ flashes Meshtastic firmware onto an nRF52 node over a USB cable을 읽어 보세요.

USB와 Bluetooth

케이블이 있다면 케이블을 쓰세요. USB는 약 1분 30초면 끝나지만, Bluetooth는 약 10분이 걸리고 이미 페어링된 휴대폰을 무전기 바로 옆에 두고 앱을 계속 열어 두어야 합니다. 플래싱 도중에 Bluetooth가 끊기면 노드가 업데이트 모드로 대기하므로, 케이블을 꽂고 다시 시도를 탭하거나 펌웨어 화면을 벗어났다면 설치를 탭하세요. USB에서는 업데이트 모드에 들어간 뒤 전송이 버벅거려도 Mesh+가 포기하기 전에 스스로 최대 세 번까지 다시 시도합니다.

업데이트가 중간에 멈췄다면

플래싱이 중간에 끊겨도 보드가 벽돌이 되지 않으며, 노드는 마무리를 기다리며 업데이트 모드에 머물러 있습니다. Mesh+의 연결 화면을 열고 노드가 업데이트 모드에서 멈췄나요?를 탭한 뒤 무전기를 연결하고 설치를 누르세요. 보드가 업데이트 모드에 들어가지 않으면 케이블을 뽑고 리셋 버튼을 빠르게 두 번 누른 다음 다시 연결해 재시도하세요. 무전기가 없어도 데모 모드로 화면을 둘러볼 수 있지만 실제로 플래싱되지는 않습니다.

자주 묻는 질문

Mesh+로 ESP32 Meshtastic 무전기도 업데이트할 수 있나요?

아니요. Mesh+는 Heltec Mesh Node T114, RAK WisBlock 4631, LILYGO T-Echo 같은 nRF52840 보드만 플래싱할 수 있습니다. Heltec V3 같은 ESP32 보드는 컴퓨터에 연결해 flasher.meshtastic.org를 이용하세요.

업데이트하면 메시지와 설정이 지워지나요?

아니요. 설정, 채팅방, 메시지는 노드에 그대로 남습니다. 플래싱이 중간에 끊겨도 노드가 업데이트 모드로 대기하므로 다시 실행하면 됩니다.

노드가 업데이트 모드에서 멈췄다면 어떻게 하나요?

연결 화면에서 노드가 업데이트 모드에서 멈췄나요?를 탭하고, 무전기를 연결한 뒤(Bluetooth라면 휴대폰을 바로 옆에 두고) 설치를 탭하세요. 업데이트 모드에 아예 들어가지 않으면 케이블을 뽑고 리셋 버튼을 빠르게 두 번 누른 다음 다시 연결해 다시 시도하세요.

이전 Meshtastic 펌웨어로 되돌릴 수 있나요?

네. 펌웨어 옵션에는 이전 버전을 포함해 Meshtastic이 내 보드용으로 공개한 모든 버전이 표시됩니다. Mesh+는 이전 펌웨어가 최신 설정을 제대로 다루지 못할 수 있다고 경고하며, 노드가 이상하게 작동하면 설정 재설정을 쓰라고 안내합니다.

Meshtastic 펌웨어 업데이트에는 얼마나 걸리나요?

USB로는 약 1분 30초, Bluetooth로는 무전기 옆에 앱을 열어 둔 채 약 10분이 걸립니다.
